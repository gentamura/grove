## Uses permitted without separate permission

You may:

- truthfully refer to Grove in articles, reviews, documentation, compatibility
  statements, issue reports, and other discussion;
- use screenshots of the official Grove application when discussing Grove;
- link to the official Grove repository;
- build and run an unmodified copy of Grove from the official source;
- redistribute an unmodified official Grove release; and
- redistribute a build made from unmodified official Grove source while using
  the Grove name and icon, provided that you identify the source revision, do
  not imply that you are the project maintainer, and preserve all copyright,
  license, and third-party notices.

Necessary changes that only adapt packaging, signing, notarization, or package
manager integration may still be described as an unmodified Grove build if they
do not change Grove's features, behavior, privacy characteristics, or visual
identity and are clearly disclosed to recipients.

## Modified versions and forks

The MIT License allows you to modify and redistribute Grove's source code.
However, a modified version that changes Grove's features, behavior, privacy
characteristics, or visual identity must:

- use a different product name;
- replace the Grove icon and other Grove-specific visual identifiers;
- avoid any presentation that suggests endorsement by or affiliation with the
  official Grove project; and
- state that it is based on Grove if it refers to Grove at all.

The truthful statement “Based on Grove” is permitted as long as the new product
is otherwise distinctly branded.

## Uses requiring permission

Separate written permission is required to:

- use a Grove Mark as the primary identity of a modified product or service;
- create a confusingly similar product name, logo, or icon;
- use a Grove Mark in a company name, domain name, application-store publisher
  name, or account name;
- use a Grove Mark on merchandise; or
- suggest sponsorship, certification, partnership, or endorsement by Grove or
  Gen Tamura.

## No endorsement or warranty

Permission to use a Grove Mark does not imply endorsement, certification,
support, or warranty. All uses must comply with applicable law and must not be
misleading.
